# ccyest.github.io

Personal website of Yichi Zhang.

**Live**: [ccyest.github.io](https://ccyest.github.io/)

## Features

- Dark / Light mode toggle
- EN / Chinese language toggle
- Research interests (LLM Infrastructure, Optimization & Benchmarking)
- Blog & video tracking with filters
- Resume with downloadable PDF
- Fully responsive (mobile + desktop)

## Stack

Vanilla HTML / CSS / JS — no build tools, no dependencies. Hosted on GitHub Pages.

## Update Content

- **Blog / Videos**: Edit the `posts` array in `js/main.js`
- **Resume**: Replace `assets/Yichi-infra.pdf` and update the timeline in `index.html`
- **Photo**: Replace `assets/photo.png`
